# 日文歌詞振??名功能說明

## 功能概述
當顯示日文歌詞時，系統會自動：
1. **檢測歌詞語言**：分析歌詞內容判斷是否為日文
2. **片假名標註**：為片假名添加對應的平假名讀音

## 示例

### 原始歌詞
```

私??????好???
```

### 顯示效果
```

```

## 功能特點

### 1. 自動檢測日文
- 檢查歌詞中日文字符（漢字、平假名、片假名）的比例
- 如果超過30%為日文字符，判定為日文歌詞

### 2. 片假名轉換
- 自動將片假名轉換為平假名
- 格式：`片假名(平假名)`
- 例如：`???(???)`

### 3. 字符類型檢測
- **漢字**：0x4E00-0x9FFF（CJK統一表意文字）
- **平假名**：0x3040-0x309F
- **片假名**：0x30A0-0x30FF

## 使用方法

使用 `/測試播放同步歌詞` 指令：
```
/測試播放同步歌詞 歌名:歌曲名稱 歌手:歌手名稱
```

當歌詞為日文時：
- 底部會顯示 `日文歌詞：片假名(平假名)` 提示
- 所有片假名會自動添加平假名標註
- 保持漢字和平假名不變

## 限制說明

### 當前實現的限制：
1. **僅處理片假名**：目前只為片假名添加讀音（因為片假名→平假名的轉換是固定的）
2. **不處理漢字**：漢字的讀音需要形態分析和詞典，實現複雜度高
3. **簡化版本**：這是一個實用的簡化方案

### 為什麼不處理漢字？
- 漢字有多種讀音（音讀/訓讀）
- 需要上下文分析（例如：「日本」讀作「???」還是「????」）
- 需要大型詞典數據（如 MeCab 需要數十MB的字典檔案）
- 需要形態分析引擎

## 未來改進方向

如果需要完整的振??名功能（包括漢字），可以考慮：

1. **使用外部API**
   - Yahoo! 日本形態分析 API
   - Google Cloud Natural Language API
   - 其他第三方日文處理API

2. **本地形態分析庫**
   - MeCab（需要字典檔案，約50MB）
   - Kuromoji（Java庫，有.NET移植版）

3. **AI模型**
   - 使用機器學習模型預測讀音
   - 需要訓練數據和計算資源

## 技術實現

### JapaneseTextHelper 類
```csharp
// 檢測漢字
IsKanji(char c)

// 檢測平假名
IsHiragana(char c)

// 檢測片假名
IsKatakana(char c)

// 片假名轉平假名
KatakanaToHiragana(string text)

// 添加片假名標註
AddKatakanaFurigana(string text)

// 檢測是否為日文
IsLikelyJapanese(string text)
```
